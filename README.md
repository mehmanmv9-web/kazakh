# Бәйтерек · Қазақ шежіресі

Интерактивное шежіре (родословная казахов) на трёх языках — қазақша, русский, English.

- **Шаг за шагом** — путь через 7 колен: от Алаша к жүзу, тайпе и руу, без поиска.
- **Родословное древо** — дерево из 380 родов и подродов, приближение пальцами.
- **Где кочевали роды** — карта расселения (схема).
- **Жеті ата** — запишите своих предков до седьмого колена.
- **Орнамент рода** — уникальный узор из мотивов ою-өрнек для каждого рода.

Сайт — один файл `index.html`, работает на GitHub Pages и офлайн.
Данные — `data.txt`, источники — `sources.md` (Востров и Муканов 1968, Муканов 1974, Википедия, skezire.kz и др.).
Версии шежіре различаются; нижние ветви и ұраны — распространённые версии.
